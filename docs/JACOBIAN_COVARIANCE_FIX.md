## 🔴 问题1：雅可比矩阵F[0][3]和F[1][3]的符号错误

### 问题描述

在位置关于速度的偏导数计算中，错误地使用了`sign_v`因子：

```c
// ❌ 修复前 (motion_model.c 第274-276行)
F[0][3] = sign_v * cos_theta * dt;     // ✗ 错误！
F[1][3] = sign_v * sin_theta * dt;     // ✗ 错误！
```

### 根本原因分析

#### 运动方程
ISO 8855自行车模型的位置更新：
$$x_{k+1} = x_k + v \cos(\theta) \Delta t$$
$$y_{k+1} = y_k + v \sin(\theta) \Delta t$$

#### 正确的雅可比元素
位置对速度的偏导数：
$$\frac{\partial x}{\partial v} = \cos(\theta) \Delta t$$
$$\frac{\partial y}{\partial v} = \sin(\theta) \Delta t$$

**关键：这些偏导数不应该依赖于速度的符号！** 速度本身已经是有符号的。

#### 为什么sign_v导致错误

当倒车时（velocity < 0, sign_v = -1）：

**场景：倒车且heading=0（指向+X方向）**
- velocity 从 -1.0 变为 -1.5（倒车加速）
- Δvelocity = -0.5（更负，倒车更快）

**使用sign_v的错误计算：**
```
F[0][3] = (-1) × cos(0°) × Δt = -1 × Δt = -Δt
Δx_predicted = F[0][3] × Δv = (-Δt) × (-0.5) = +0.5Δt  ❌ 错了！
```
预测x增加，但实际倒车时x应该减少！

**正确的计算（不用sign_v）：**
```
F[0][3] = cos(0°) × Δt = +Δt
Δx_predicted = F[0][3] × Δv = (+Δt) × (-0.5) = -0.5Δt  ✓ 正确！
```
velocity的负号自动处理了方向！

### 物理直观

velocity的符号已经完整编码了车辆的运动方向：
- v > 0：前进，位置沿heading方向增加
- v < 0：后退，位置沿heading反向增加（即减少）

**再乘以sign_v相当于双重反向**，破坏了这个关系。

### 修复方案

```c
// ✅ 修复后 (motion_model.c 第274-276行)
F[0][3] = cos_theta * dt;              // ✓ 移除sign_v
F[1][3] = sin_theta * dt;              // ✓ 移除sign_v
```

### 影响范围

这个错误影响了卡尔曼滤波的协方差矩阵更新（P = F·P·F^T + Q），导致：
1. 位置不确定性计算错误
2. Y方向的卡尔曼增益被压制
3. 最终Y坐标在倒车时始终为0

## 🔴 问题2：协方差矩阵初始化过于乐观

### 问题描述

```c
// ❌ 修复前 (kalman_filter.c 第252-254行)
for (int i = 0; i < 5; i++) {
    kf->state.P[i][i] = 0.1;           // 所有状态都是0.1
}
```

### 问题分析

#### 协方差矩阵的含义
对角元素P[i][i]表示**第i个状态的方差**（不确定性的平方）：
- P[0][0] = 0.1 意味着 σ_x = √0.1 ≈ 0.316 m
- P[1][1] = 0.1 意味着 σ_y = √0.1 ≈ 0.316 m

#### 为什么这个值太小

对于一个**无GPS、仅基于轮速计和IMU的定位系统**：
1. **初始位置完全依赖外部提供** - 可能有10米以上的误差
2. **只有300ms左右的运动** - 位置累积误差不会太大
3. **0.1m的初始不确定性告诉卡尔曼** - "我们非常确信初始位置"

#### 后果：卡尔曼增益被压制

卡尔曼增益的第i行：
$$K_i = \frac{P_i H^T}{H P H^T + R}$$

当P太小时，分子变小，K变小，导致：
1. **测量更新影响减弱** - 即使有准确的传感器，也难以修正估计
2. **依赖纯预测** - 回到odometry累积误差问题
3. **低速时尤其差** - 轮速计噪声相对变大

### 物理直观

类比医学诊断：
- **初始P=0.1**："我们已经做了很多检查，非常确信患者的诊断"
  - 后续新的医学检查不太会改变诊断
- **初始P=10.0**："这是初步诊断，还需要更多检查"
  - 后续医学检查会显著影响最终诊断

### 修复方案

根据物理意义设置合理的初始不确定性：

```c
// ✅ 修复后 (kalman_filter.c 第252-254行)
kf->state.P[0][0] = 10.0;   // x位置：±10米初始不确定性
kf->state.P[1][1] = 10.0;   // y位置：±10米初始不确定性
kf->state.P[2][2] = 1.0;    // heading：±1弧度（约±57°）
kf->state.P[3][3] = 0.5;    // velocity：±0.5 m/s
kf->state.P[4][4] = 0.2;    // steering_angle：±0.2弧度（约±11°）
```

#### 设置依据

| 状态 | 新初值 | 标准差(σ) | 理由 |
|-----|--------|---------|------|
| x | 10.0 | 3.16 m | 无GPS，可能的初始误差范围 |
| y | 10.0 | 3.16 m | 无GPS，可能的初始误差范围 |
| θ | 1.0 | 1.0 rad | 初始航向可能有1弧度误差 |
| v | 0.5 | 0.707 m/s | 初始速度估计有0.7 m/s误差 |
| δ | 0.2 | 0.447 rad | 转向角初始误差较小 |

### 影响范围

这个修复增强了卡尔曼滤波器的**自适应能力**：
1. 更信任传感器测量
2. 允许协方差随时间收敛
3. 在低速下也能有效更新
4. Y坐标能够正常累积

## 🎯 关键要点总结

1. **速度是有符号的** - 倒车时v<0，不需要额外的sign_v因子
2. **初始不确定性应该现实** - 10m的初始位置误差是合理的
3. **雅可比矩阵的数值** - 直接影响协方差和卡尔曼增益
4. **低速运动需要特殊处理** - 轮速计的离散化误差需要权衡
