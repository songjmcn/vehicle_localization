# ISO 8855 车辆坐标系规范

## 📋 概述

ISO 8855是国际标准化组织（ISO）制定的车辆动力学和控制性能测试方法标准，其中定义了标准的车辆坐标系。本文档详细说明ISO 8855坐标系的定义及其与当前系统的关系。

**标准编号：** ISO 8855  
**标准名称：** Road vehicles - Vehicle dynamics and road-holding ability - Vocabulary and handling characteristics - Evaluation methods  
**发布日期：** 1991（修订：2011）

---

## 🎯 ISO 8855 坐标系定义

### 基本特性

| 属性 | 值 |
|------|-----|
| **坐标原点** | 后轮轴中心（RAC, Rear Axle Center） |
| **X轴** | 沿车辆纵向轴，指向车前方 |
| **Y轴** | 沿车辆横向轴，指向车左方 |
| **Z轴** | 沿车辆竖直轴，指向车上方 |
| **手性** | 右手坐标系 |
| **运动参考** | 车体固定坐标系（Body-fixed） |

> **注意**：本实现采用ISO 8855标准中的**后轮轴中心（RAC）**作为坐标原点，而非质心（CG）。这是针对轮式车辆自动驾驶定位的标准实现，具有以下优点：
> - 后轮编码器直接提供原点处的纵向位移
> - 非完整约束（后轮不侧滑）自然满足
> - 轨迹控制和路径规划更直观

### 坐标系可视化

```
               Y轴(左方)
               ←───
               │
       Z轴(上)│  ┌────────────┐
       ↑      │  │   前方     │
       │      │  │ ───────── │
       └──────┼──│ 质心(原点) │
       │      │  │ (CG)      │
       X轴────┴──│ ───────── │
      (前方)     │   后方    │
              │  └────────────┘
              →
           Y轴(右方)
```

### 详细参数

```
=== X轴 (纵向/前后向) ===
• 原点方向：车前方
• 正方向：指向车前
• 负方向：指向车后
• 参数：纵向位移、纵向速度、纵向加速度

=== Y轴 (横向/左右向) ===
• 原点方向：车左方
• 正方向：指向车左（或驾驶员视角的左）
• 负方向：指向车右
• 参数：横向位移、横向速度、横向加速度

=== Z轴 (竖直向) ===
• 原点方向：车上方
• 正方向：指向车顶上方
• 负方向：指向车底下方
• 参数：竖直位移、俯仰、侧倾
```

## 📐 ISO 8855 坐标系的角度定义

### 欧拉角（Euler Angles）

ISO 8855 使用以下角度定义：

```
1. 横滚角 (Roll Angle, φ)
   • 绕X轴旋转
   • 单位：弧度 (rad) 或 度 (deg)
   • 范围：通常 [-π, π] 或 [-180°, 180°]
   • 正向：车身向左倾斜（左轮抬起）
   • 负向：车身向右倾斜（右轮抬起）

2. 俯仰角 (Pitch Angle, θ)
   • 绕Y轴旋转
   • 单位：弧度 (rad) 或 度 (deg)
   • 范围：通常 [-π/2, π/2] 或 [-90°, 90°]
   • 正向：车前抬起（车头上翘）
   • 负向：车前下沉（车头下沉）

3. 偏航角 (Yaw Angle, ψ)
   • 绕Z轴旋转
   • 单位：弧度 (rad) 或 度 (deg)
   • 范围：通常 [-π, π] 或 [-180°, 180°]
   • 正向：逆时针旋转（从上往下看）
   • 负向：顺时针旋转
   • 注：北向 = 0° 或 πm 需要根据应用定义
```

### 角速率

```
ω_x = dφ/dt  (横滚角速率)    [rad/s]
ω_y = dθ/dt  (俯仰角速率)    [rad/s]
ω_z = dψ/dt  (偏航角速率)    [rad/s]
```

## 📍 全局坐标系与 ISO 8855 的关系

### 地理坐标系 (Geographic Frame)

ISO 8855 标准中还定义了地理坐标系（相对于地面固定）：

| 属性 | 值 |
|------|-----|
| **参考** | 相对地面固定 |
| **原点** | 可自定义（通常为初始位置或参考点） |
| **X轴** | 可定义为北向、东向或其他 |
| **Y轴** | 垂直于X轴，在水平面内 |
| **Z轴** | 竖直向上 |

### 坐标系转换

从车体坐标系（ISO 8855）到地理坐标系的转换：

```
[X_geo]   [cos(ψ)  -sin(ψ)] [X_body]   [X_geo_0]
[Y_geo] = [sin(ψ)   cos(ψ)] [Y_body] + [Y_geo_0]
[Z_geo]   [   0        0  ] [Z_body]   [Z_geo_0]

其中：
  ψ = 偏航角（相对地理坐标系的北向）
  [X_geo_0, Y_geo_0, Z_geo_0] = 质心位置（地理坐标系）
```

### 东北向坐标系 (East-North Frame)

我们当前系统使用的"全局坐标系"是东北向的：

| 特性 | 值 |
|------|-----|
| **X轴** | 东向 (East) |
| **Y轴** | 北向 (North) |
| **Z轴** | 上向 (Up) |
| **原点** | 初始化时的质心位置 |

**与ISO 8855地理坐标系的关系：**
- 我们的X轴（东向）对应ISO地理坐标系的第一轴
- 我们的Y轴（北向）对应ISO地理坐标系的第二轴
- 完全兼容，只是轴的定义略有不同

## 🔗 ISO 8855 参数映射

### 车体运动参数

**在ISO 8855框架下的标准表示：**

```c
// ISO 8855 定义的车体运动参数
typedef struct {
    // 位置 (相对质心)
    float x_body;              // X轴位置 (m)
    float y_body;              // Y轴位置 (m)
    float z_body;              // Z轴位置 (m)
    
    // 速度 (车体坐标系)
    float v_x;                 // 纵向速度 (m/s)
    float v_y;                 // 横向速度 (m/s)
    float v_z;                 // 竖直速度 (m/s)
    
    // 加速度 (车体坐标系)
    float a_x;                 // 纵向加速度 (m/s²)
    float a_y;                 // 横向加速度 (m/s²)
    float a_z;                 // 竖直加速度 (m/s²)
    
    // 姿态角 (Euler角)
    float phi;                 // 横滚角 φ (rad)
    float theta;               // 俯仰角 θ (rad)
    float psi;                 // 偏航角 ψ (rad)
    
    // 角速率 (车体坐标系)
    float omega_x;             // 横滚角速率 (rad/s)
    float omega_y;             // 俯仰角速率 (rad/s)
    float omega_z;             // 偏航角速率 (rad/s)
    
    uint32_t timestamp;
} ISO8855_VehicleState_t;
```

### 与当前系统的映射

```
当前系统                          ISO 8855
───────────────────────────────────────────
VehicleState_t.v                 → v_x (假设平面运动)
VehicleState_t.delta             → 前轮转向角 δ
SensorReadings_t.accel_x         → a_x
SensorReadings_t.accel_y         → a_y
SensorReadings_t.gyro_z          → omega_z
SensorReadings_t.steering_angle  → δ (转向角)
```
