# 低速车辆定位精确计算方案

## 1. 系统概述

在低速状态（1 m/s < v < 1.5 m/s）下，采用多传感器融合方案实现精确定位：
- **IMU**：提供线性加速度和角速度
- **轮速计（Wheel Odometry）**：提供精确的速度和距离信息
- **转向角**：提供车辆方向信息
- **Kalman滤波**：融合多传感器数据

## 2. 车辆运动学模型

### 2.1 单轨模型（Bicycle Model）

对于低速状态，采用经典的单轨模型：

```
x_{k+1} = x_k + v * cos(θ_k + δ) * Δt
y_{k+1} = y_k + v * sin(θ_k + δ) * Δt
θ_{k+1} = θ_k + v * tan(δ) / L * Δt
```

其中：
- (x, y)：车辆位置
- θ：车辆航向角
- v：车体速度（考虑正负）
- δ：前轮转向角
- L：轴距（2.7m）
- Δt：时间间隔

### 2.2 考虑前进和后退

标准单轨模型对后退方向不准确。改进模型：

```
x_{k+1} = x_k + |v| * cos(θ_k + sign(v) * δ) * Δt
y_{k+1} = y_k + |v| * sin(θ_k + sign(v) * δ) * Δt
θ_{k+1} = θ_k + sign(v) * |v| * tan(δ) / L * Δt
```

## 3. 传感器融合架构

### 3.1 状态向量

x = [x, y, θ, v, δ]^T

- x, y：位置（m）
- θ：航向角（rad）
- v：速度（m/s）
- δ：转向角（rad）

### 3.2 测量模型

三个传感器的测量值：
- 轮速计：速度测量
- IMU加速度：侧向加速度测量
- 转向角：方向测量

## 4. 低速状态下的关键挑战

### 4.1 挑战1：轮速计漂移
- **问题**：低速时，轮滑动和静摩擦变化明显
- **解决**：使用IMU加速度修正，检测轮滑

### 4.2 挑战2：IMU噪声和漂移
- **问题**：IMU陀螺仪零偏和噪声积分产生的漂移
- **解决**：使用轮速计校准，限制积分时间

### 4.3 挑战3：转向延迟
- **问题**：方向盘转角到实际车头转向存在延迟
- **解决**：建立转向动力学模型或使用观测器

### 4.4 挑战4：前后转向差异
- **问题**：后退时转向角符号相反
- **解决**：在运动学模型中引入符号函数

## 5. 低速特异性处理

### 5.1 静止检测
```
if |wheel_velocity| < v_threshold (e.g., 0.05 m/s):
    - 使用IMU检测是否真正停止
    - 停止更新位置，只更新角度
    - 降低过程噪声
```

### 5.2 转向角缓和
```
δ_filtered = α * δ_measured + (1 - α) * δ_previous
α = f(v)  # 低速时α较小，减少噪声
```

### 5.3 速度符号确定
- 优先使用轮速计的反向信号
- 备选方案：IMU加速度方向
- 可选：集成里程表传感器

## 6. Kalman滤波配置

### 6.1 过程噪声协方差 Q（低速调整）

```
Q = diag([σ²_x, σ²_y, σ²_θ, σ²_v, σ²_δ])

低速推荐值：
- σ_x, σ_y ≈ 0.005 m (基于运动模型误差)
- σ_θ ≈ 0.01 rad
- σ_v ≈ 0.02 m/s (低速时轮滑动较多)
- σ_δ ≈ 0.02 rad
```

### 6.2 测量噪声协方差 R

```
R = diag([σ²_wheel, σ²_imu_acc, σ²_steering])

推荐值：
- σ_wheel ≈ 0.01 m/s (轮速计）
- σ_imu_acc ≈ 0.1 m/s² (IMU加速度)
- σ_steering ≈ 0.05 rad (转向角)
```

## 7. 算法流程

```
1. 初始化
   - 设置 x₀ = [0, 0, 0, 0, 0]ᵀ
   - 初始化 P₀ = diag(0.01, 0.01, 0.01, 0.01, 0.01)

2. 循环（每个时间步Δt）
   a) 预测步骤
      - 读取转向角 δ_meas
      - 读取轮速计 v_wheel
      - 运行运动学模型
      - 更新状态估计 x̂⁻
      - 更新协方差 P⁻
   
   b) 更新步骤
      - 读取IMU加速度 a_imu
      - 计算卡尔曼增益
      - 更新状态 x̂⁺
      - 更新协方差 P⁺
   
   c) 检测异常
      - 检查轮滑动（加速度 > 阈值）
      - 检查静止状态
      - 调整噪声参数
```

## 8. 性能指标

在低速状态下的目标指标：

| 指标 | 目标值 | 说明 |
|------|-------|------|
| 位置误差 | < 0.1 m | 1秒内累计误差 |
| 角度误差 | < 2° | 航向角误差 |
| 更新频率 | 20-50 Hz | 足以处理低速动态 |
| 响应延迟 | < 100 ms | 转向响应延迟 |
| 静止时漂移 | < 0.05 m/min | 长时间静止状态 |

## 9. 传感器标定

### 9.1 轮速计标定
```
实际距离 vs 轮速计读数的线性关系
calibration_factor = actual_distance / odometry_distance
```

### 9.2 IMU标定
- 零偏校准：车辆静止时采样
- 噪声方差：计算静止时的标准差
- 尺度因子：已知加速度下的响应

### 9.3 转向角标定
- 直行时转向角应为0
- 最大转向角范围确定
- 线性性检查

## 10. 常见故障和排查

| 问题 | 征象 | 解决方案 |
|------|------|--------|
| 轮滑动 | 位置突跳 | 检测加速度异常，临时降低轮速权重 |
| IMU漂移 | 持续旋转 | 定期重置，使用转向角校准 |
| 测量延迟 | 转向滞后 | 引入动态延迟补偿 |
| 混合运动 | 不稳定发散 | 增加过程噪声或使用自适应滤波 |
