## 🔄 坐标转换原理

### ISO 8855车体坐标系
```
      ↑ Y (左)
      │
  [○] ├─────→ X (前)
  /  \│
 后轮轴中心
```

### 转换步骤

#### Step 1: 地理差值计算
```
Δlat = (当前纬度 - 原点纬度) × π/180
Δlon = (当前经度 - 原点经度) × π/180
```

#### Step 2: 大地投影（WGS84地理坐标系 → 本地投影）
```
dy = Δlat × R_earth         # 南北距离（米）
dx = Δlon × R_earth × cos(φ)  # 东西距离（米）
  其中：R_earth = 6371000米，φ = 原点纬度
```

#### Step 3: 旋转变换（投影坐标系 → 车体坐标系）
```
设θ = 原点航向角（弧度）

x_车体 = dx × cos(θ) + dy × sin(θ)     # 纵向
y_车体 = -dx × sin(θ) + dy × cos(θ)    # 横向
```

#### Step 4: 相对航向角
```
heading_rel = 当前航向角 - 原点航向角
规范化到 [-180°, 180°]
```

## 🎯 与vehicle_localization.csv的对比

转换后的 `rtk_converted.csv` 可与 `vehicle_localization.csv` 进行对比分析：

### 相同点
- ✅ 使用相同的坐标系（ISO 8855车体坐标系）
- ✅ 使用相同的原点（第一个数据点）
- ✅ 时间轴对应

### 不同点
- RTK数据来自GPS，vehicle_localization来自卡尔曼滤波
- RTK数据频率可能不同（需要时间戳匹配）
- RTK数据包含质量信息，vehicle_localization不包含

### 对比方法
```python
import pandas as pd
import numpy as np

rtk = pd.read_csv('rtk_converted.csv', delimiter=';')
vl = pd.read_csv('vehicle_localization.csv', delimiter=';')

# 按时间戳对齐
for i, row in vl.iterrows():
    ts = row['timestamp'] / 1000  # 转换为秒
    # 查找匹配的RTK数据...
    rtk_row = rtk[rtk['timestamp'].abs() - ts < 0.01].iloc[0]
    
    # 计算偏差
    dx = row['x'] - rtk_row['x']
    dy = row['y'] - rtk_row['y']
    distance_error = np.sqrt(dx**2 + dy**2)
    
    print(f"时间：{ts:.2f}s，位置误差：{distance_error:.4f}m")
```

## 🐛 故障排除

### 问题：File not found
**原因**：输入文件不在正确位置  
**解决**：确保 `rtk_can.csv` 在项目根目录

### 问题：数据行数少于期望
**原因**：某些行有格式错误，被跳过  
**解决**：检查CSV格式是否正确（分隔符为 `;`）

### 问题：所有坐标都是0
**原因**：所有数据点位置相同  
**解决**：检查输入数据是否有效
